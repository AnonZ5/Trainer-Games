# Omnitrainer trainers

Trainers for PC games, used through **Omnitrainer Launcher**.

## How to use

1. Open the [`trainers` release](https://github.com/AnonZ5/Trainer-Games/releases/tag/trainers)
   and download **OmnitrainerLauncher.exe**.
2. Run it (Windows 10 or 11, nothing else to install).
3. Click a game and confirm where it is installed. Its trainer is downloaded, and from then
   on it opens by itself a few seconds after you start the game. Closing the launcher window
   keeps it running in the tray.

The other files in the release (the trainer engine and the `game-*.pak` packages) are
downloaded by the launcher; they only work through it.

## Fair play

Some supported games have online play. Use trainers only in your own or your friends'
sessions: cheating on public servers ruins the game for others and can get you banned.
